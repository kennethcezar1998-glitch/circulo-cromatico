Prévia interativa do painel

Círculo Cromático RYB
para Photoshop

Um painel com círculo RYB/RGB, harmonias, paletas e sugestão de luz e sombra, ligado às cores de primeiro plano e plano de fundo do Photoshop.

Baixar o plugin (.ccx) Como instalar Versão web Código no GitHub

Instalação rápida

  1. Baixe o arquivo Circulo-Cromatico.ccx.
  2. Com o Photoshop fechado, dê dois cliques nele e confirme no aplicativo Creative Cloud.
  3. No Photoshop, abra Plug-ins › Círculo Cromático RYB › Círculo Cromático.

Requer Photoshop 2024 (versão 25) ou mais novo, no Windows ou no Mac.

No Photoshop

  • Arrastar no círculo muda a cor de primeiro plano na hora.
  • Conta-gotas, seletor de cores e os atalhos X e D atualizam o círculo.
  • Clique numa amostra para usá-la como cor de primeiro plano; Alt + clique copia o HEX.

Sobre a prévia: aqui no navegador o painel funciona por completo, mas sem a ligação com o Photoshop. Clicar numa amostra copia o HEX.
